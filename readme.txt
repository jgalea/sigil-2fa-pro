Method policy, branding, settings portability, password-reset protection, destinations, sign-in bypass and audit history for Sigil.

== Description ==

Sigil Pro is an add-on to the free Sigil plugin and needs it installed and active. It is free. Updates arrive through the normal WordPress update screen, from the add-on's GitHub releases.

== Switching from the combined build ==

Earlier Pro releases replaced the free plugin with a single package that carried Pro inside it. From 0.5 the two are separate plugins.

1. Update Sigil to 0.5 or later from the Plugins screen. This replaces the combined build with the plain free plugin; none of your settings are touched.
2. Upload and activate Sigil Pro (this plugin). Your method policy, branding and other Pro settings are read from the same options as before, so nothing needs to be entered again. Pro no longer asks for a licence key; any saved key is ignored.
3. Future Sigil updates from WordPress.org leave Pro in place.
